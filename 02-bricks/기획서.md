# 물풍선 팡팡 게임 기획서

## 1. 프로젝트 개요

- **프로그램 이름:** 물풍선 팡팡
- **목적:** 밝은 물놀이 분위기에서 바늘로 물풍선을 터뜨리고 바나나를 피하는 웹 브라우저 게임
- **실행 환경:** 1024 × 768 해상도의 최신 데스크톱 웹 브라우저
- **저장 위치:** `myenv_vibe/02-bricks`

## 2. 확정 사양

### 2.1 화면 구성

- 게임 영역은 가로 1000px, 세로 700px로 한다.
- 게임 영역은 화면 가운데에 배치한다.
- 게임 안쪽은 하늘색 물놀이 배경과 흰색 거품으로 꾸민다.
- 페이지 바깥에는 하늘색·노란색·분홍색 그라데이션을 사용한다.
- 게임 영역에는 둥근 하늘색 테두리와 그림자를 표시한다.
- 점수, 남은 기회, 상태 안내 문구는 게임 영역 위쪽에 표시한다.

### 2.2 물풍선

- 물풍선은 7층, 각 층 9개, 총 63개로 구성한다.
- 물풍선 영역은 너비 72px, 높이 48px로 한다.
- 타원, 매듭, 반사광을 그려 통통한 물풍선처럼 표현한다.
- 분홍색, 보라색, 하늘색, 주황색, 초록색을 번갈아 사용한다.
- 이웃한 물풍선의 높이를 8px씩 번갈아 바꾸어 지그재그로 배치한다.
- 바늘과 충돌한 물풍선은 터져 사라지고 점수 10점을 얻는다.
- 총 63개 중 일정한 순서의 13개 물풍선 안에 바나나를 숨긴다.
- 바나나가 든 물풍선도 겉모습은 일반 물풍선과 같게 한다.

### 2.3 플레이어 캐릭터

- 받침대 대신 너비 110px, 높이 80px의 노란 오리 우비 캐릭터를 사용한다.
- 캐릭터는 특정 기존 게임 캐릭터를 복제하지 않은 새로운 디자인이다.
- 투명 배경 이미지 `water_arcade_player.png`를 사용한다.
- 캐릭터는 게임 영역 아래쪽에서 왼쪽·오른쪽 방향키로 움직인다.
- 캐릭터가 게임 영역 밖으로 나가지 않도록 제한한다.

### 2.4 바늘

- 기존 원형 공과 다중 공 기능을 제거하고 바늘 1개만 사용한다.
- 바늘은 회색 몸통, 흰색 끝, 분홍색 손잡이로 그린다.
- 바늘 끝은 항상 이동 방향을 향하도록 회전한다.
- 시작 전에는 플레이어 캐릭터의 가운데 위에 정지시킨다.
- 진행 중 벽, 물풍선, 플레이어 캐릭터에 부딪히면 반사된다.
- 가로·세로 초기 이동 속도는 각각 초당 약 300px로 한다.

### 2.5 바나나 위험 요소

- 바나나가 든 물풍선이 터지면 그 자리에서 바나나가 떨어진다.
- 바나나는 초당 180px로 떨어지면서 회전한다.
- 바나나가 화면 아래로 빠져나가면 안전하게 피한 것으로 처리한다.
- 바나나가 플레이어 캐릭터에 닿으면 남은 기회를 1회 줄인다.
- 기회가 남으면 떨어지던 바나나를 모두 없애고 캐릭터와 바늘을 초기화한다.

### 2.6 게임 진행

1. 페이지를 열면 `스페이스키를 눌러 시작하세요`라고 표시한다.
2. 스페이스키를 누르면 바늘이 움직이며 게임이 시작된다.
3. 바늘이 물풍선과 충돌하면 물풍선이 터지고 점수가 10점 증가한다.
4. 일부 물풍선에서는 바나나가 떨어지며 플레이어는 방향키로 피한다.
5. 바나나에 맞거나 바늘을 놓치면 남은 기회가 1 감소한다.
6. 남은 기회는 처음에 3회로 시작한다.
7. 기회가 남아 있으면 스페이스키로 계속한다.
8. 물풍선 63개를 모두 터뜨리면 승리한다.
9. 남은 기회가 0이면 게임이 종료되고 중앙에 큰 `LOSE` 문구를 표시한다.
10. 승리 또는 게임 종료 뒤 스페이스키를 누르면 새 게임을 시작한다.

### 2.7 기술 및 파일 구성

- 별도 게임 라이브러리 없이 HTML, CSS, 순수 자바스크립트로 작성한다.
- 게임 화면은 HTML의 `<canvas>` 요소를 사용한다.

```text
02-bricks/
├── 기획서.md
├── brick_game.html
├── brick_game.css
├── brick_game.js
└── water_arcade_player.png
```

- 기존 `lee_kwang_soo_brick.png`는 삭제하지 않지만 게임에서 사용하지 않는다.
- `brick_game.html`에서 CSS와 자바스크립트 파일을 불러온다.
- 게임 실행 중 인터넷이나 외부 서비스를 사용하지 않는다.

## 3. 조작 방법

| 키 | 기능 |
|---|---|
| 스페이스키 | 게임 시작, 재출발, 새 게임 시작 |
| 왼쪽 방향키(←) | 캐릭터를 왼쪽으로 이동 |
| 오른쪽 방향키(→) | 캐릭터를 오른쪽으로 이동 |

## 4. 화면 문구

- 대기: `스페이스키를 눌러 시작하세요`
- 진행: `바나나는 피하고 물풍선을 터뜨리세요!`
- 바늘을 놓침: `바늘을 놓쳤습니다! 스페이스키를 눌러 계속하세요`
- 바나나 충돌: `바나나에 맞았습니다! 스페이스키를 눌러 계속하세요`
- 승리: `축하합니다! 모든 물풍선을 터뜨렸습니다. 스페이스키를 눌러 다시 시작하세요`
- 게임 종료: `게임 오버! 스페이스키를 눌러 다시 시작하세요`
- 게임 종료 중앙 문구: `LOSE`

## 5. 확정한 추가 기준

1. 물풍선은 기존 7층 구조를 유지하여 7 × 9 = 63개로 정한다.
2. 바나나는 약 5개당 하나가 되도록 총 13개로 정한다.
3. 바나나에 맞으면 게임이 즉시 끝나는 대신 남은 기회가 1회 줄어든다.
4. 조작은 키보드 방향키만 사용한다.
5. 다중 공 기능을 완전히 제거하고 바늘 1개만 사용한다.

## 6. 완료 기준

- [ ] HTML, CSS, 자바스크립트 파일이 분리되어 있다.
- [ ] 1024 × 768 화면에서 게임 전체가 잘리지 않고 보인다.
- [ ] 밝은 물놀이 배경과 여러 색의 물풍선 63개가 표시된다.
- [ ] 플레이어 캐릭터가 방향키로 움직인다.
- [ ] 스페이스키를 누르기 전에는 바늘이 움직이지 않는다.
- [ ] 바늘과 벽, 물풍선, 캐릭터의 충돌이 처리된다.
- [ ] 물풍선을 터뜨리면 10점씩 증가한다.
- [ ] 바늘은 항상 1개만 존재한다.
- [ ] 바나나 물풍선 13개가 터질 때 바나나가 떨어진다.
- [ ] 바나나를 피하면 사라지고 맞으면 남은 기회가 감소한다.
- [ ] 바늘을 놓치면 남은 기회가 감소한다.
- [ ] 게임 오버 때 중앙에 큰 `LOSE`가 표시된다.
- [ ] 승리와 게임 종료 후 새 게임을 시작할 수 있다.
- [ ] 브라우저 개발자 도구 콘솔에 오류가 없다.
