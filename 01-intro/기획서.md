# 기획서: 자기소개 웹페이지

## 누가 쓰나

수업에서 처음 만난 친구들

## 만들 것

가상의 여자 대학생을 소개하는 한 페이지짜리 웹페이지

## 기능

1. 이름과 별명과 한 줄 소개
   - 가상 이름: 한도윤
   - 별명: 두부
   - 인물 설정: 22세 여자 대학생
   - 한 줄 소개: 사진 찍기와 카페 탐방을 좋아하는 여자 대학생입니다.
   - 이름은 실명이 아닌 가상 이름을 사용하며, 별명은 이후 요청에서 알려 주면 변경한다.
2. 좋아하는 것 3가지
   - 떡볶이
   - 고양이
   - 카페 탐방
3. 싫어하는 것 3가지를 좋아하는 것과 함께 표시
   - 싫어하는 것: 지각하기, 시끄러운 공부 공간, 비 오는 날 젖은 신발
   - 싫어하는 것은 실습용 가상 설정이다.
4. 누르면 옷이 바뀌는 인형 같은 아바타
   - HTML과 CSS로 직접 그린 긴 머리 여자 아바타를 사용한다.
   - 아바타를 누르면 보라색 티셔츠, 줄무늬 티셔츠, 멜빵바지, 후드티가 순서대로 반복된다.
   - 현재 옷 이름을 표시하고 키보드의 엔터나 스페이스 키로도 바꿀 수 있다.

## 조건

- `index.html` 파일 하나에 HTML, CSS, JavaScript만 사용
- 외부 라이브러리, 서버, 데이터베이스는 사용하지 않음
- 실명, 연락처, 사진은 넣지 않음
- 실제 개인정보가 아닌 가상 정보만 사용
- 화면 문구와 코드 주석은 모두 한국어로 작성
- 배경색은 보라색으로 지정
- 외부 사이트 연결 없이 자기소개 화면과 옷 변경이 인터넷 없이 작동
- 좋아하는 것과 싫어하는 것 각각 3가지를 동시에 표시
- 휴대전화에서는 내용을 세로로 배치

- [ ] 싫어하는 것 3가지가 좋아하는 것과 함께 보인다.

- [ ] 키보드로 아바타 버튼을 선택해 옷을 바꿀 수 있다.
- [ ] 여자 대학생 설정과 긴 머리 아바타가 반영되어 있다.
